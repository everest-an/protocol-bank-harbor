The problem

Agents get a wallet.
Not a mandate.

When a human delegates a budget to an AI agent, the agent usually gets a private key and unrestricted access. There is no server-enforced limit between the human's intent and the agent's payment.

  • An agent can overspend the budget.
  • An agent can pay an unapproved vendor.
  • An agent can keep spending after the human revokes permission.
The solution

A mandate the agent
cannot widen.

01 · Identity

ME ID is the root

The human is verified through the ME mainnet DID module. The mandate is bound to the ME ID and the captain wallet.

02 · Policy

Deny by default

Vendor allowlist, per-transaction cap, monthly cap, expiry, and human approval are checked before a transaction is built.

03 · Settlement

MEC with an audit memo

Approved payments are native MEC transfers on ME with the ME ID, mandate ID, agent ID, vendor, amount, and receipt hash.

04 · Control

Revoke instantly

The human can revoke at any time. Every later request is blocked and recorded.

Official ME Bridge

USDC/USDT in.
MEC is separate.

The adapter uses the official Meta Earth Bridge at bridge.mec.me. BSC and TRON USDC/USDT → ME, minimum 1 USDC. It records the source and destination transaction hashes. It does not custody funds or reimplement the bridge.

Important: the bridge does not mint MEC. Bridged USDC still needs a swap to MEC for gas.
